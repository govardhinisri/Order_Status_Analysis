# Order_Status_Analysis
Analyze retail order statuses using SQL to calculate the count and percentage of Completed, Cancelled, and Returned orders. Apply COUNT(), GROUP BY, subqueries, and ROUND() to summarize order distribution and identify the most common order status.

This project analyzes retail sales data using SQL and Power BI to understand order status, revenue trends, cancellation rates, city-wise performance, and product category performance. The goal is to transform raw sales data into meaningful business insights through SQL queries and interactive Power BI visualizations.
